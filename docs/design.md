# 设计约定

沿用 Owlbay 个人站的设计体系：「安静的索引终端」。一块暖近黑底、一组暖灰文字、一种陶土色；结构靠线，不靠色块、阴影或圆角。所有取值只在 `src/styles/tokens.css` 定义。

## 颜色

- 深色默认：底 `--bg` #141413，字 `--ink` #faf9f5，次级 `--ink-2` / `--ink-3`；`--ink-4` 只做装饰，不承载需要阅读的文字。
- 浅色主题是同一套关系的反相，只替换变量值。
- **唯一强调色**陶土橙 `--accent`：像素猫头鹰、字墙点亮词、光标、当前位置细线、焦点环。不做按钮底、链接色或标题色。
- **选中 = 反白**（`--selected-bg` 底 + `--selected-ink` 字）：分段控件当前项、搜索结果当前项。**当前位置 = 陶土色 2px 细线**：顶栏当前页。

## 字体

- Geist：标题、正文、导航、说明。Geist Mono：只用于数据（ID、数值、价格、日期、路径、快捷键、角标），一律等宽数字。
- 字重只有 400 / 500；层级靠字号与颜色阶。
- 角标（`.corner`）：等宽 11px、500、0.06em、拉丁字母大写——内容放计数或日期，不放区分大小写的路径。

## 结构

- 零圆角、零阴影。分开两块东西时画 1px 线（`--line` / `--line-soft` / `--line-strong`）或换一档底色。
- 内容页外框 `.page`：左右两条 1px 实线与顶栏内容边缘对齐，从顶栏贯穿到页面底部；页面主体撑满剩余高度。全站不设页脚。
- 分区用 `SectionFrame`，放在 `.page` 内：顶部一条 4px/4px 虚线横贯两条竖线，右上计数，左下来源，右下快照日期。
- 一行一条的列表用 `.list-row`（52px、`--line-soft` 底线、hover `--hover-row`），组件只定义列布局；表头与行使用同一字号，保证 `ch` 列宽对齐。
- 页面标题用 `PageHeader`（`--fs-h1`），始终比分区标题（`--fs-h2`）大一级。
- 内容宽度按视口比例：两侧留白 `max(20px, 4vw)`，超宽屏封顶 2400px；`.page` 的直接子项 `min-width: 0`，宽内容只在自身容器内横向滚动。控件高 44px，搜索框 56px。

## 页面

- **首页**：一屏，不画外框。顶栏、字墙 hero、页脚。字墙全部由模型名称铺成，指针附近点亮为陶土色，点击直达模型；中央两行标题 + 搜索框（结果面板 `--bg-panel` 底）。
- **模型列表**：标题区（搜索框 + 类型、模型厂商两个下拉，同一行，状态同步到 URL）+ 模型分区；模型厂商列带 logo。分区右上角「显示全部信息」切换为 16 列全字段视图（`?view=full`，选择存 localStorage），表格区横向滚动、模型列固定。
- **模型详情**：规格分组（API、上下文、输入输出、思考、价格、能力、源信息）、调用方式（每个端点可复制）、标准 JSON、官方来源；标题区带厂商 logo 与「报告数据错误」链接（预填数据更正 Issue 模板）。
- **文档**：简介、接口、在线调试、响应结构、字段、调用示例、数据。

## 组件

- 顶栏 `TopNav`：品牌文字、导航（`src/lib/nav.ts`）、反馈（GitHub Issues）、语言下拉 `LangMenu`、主题。
- 地址行 `Endpoint`：方法 + 完整地址 + 复制按钮，可插入操作按钮。
- 代码块 `CodeBlock`：标题栏 + 复制按钮。复制逻辑统一在 `src/scripts/copy.ts`。
- 在线调试 `Playground`：`Endpoint` + 发送按钮 + 状态 / 耗时 / 大小 / 模型数 + 响应正文。
- 筛选下拉 `FilterMenu`：触发器显示当前选择，选项带计数，可带厂商 logo 与菜单内搜索；选中项反白。
- 厂商 logo `VendorLogo`：`@lobehub/icons-static-svg` 单色图标构建时内联，`fill="currentColor"` 随文字色适配深浅主题；`data/vendors/<id>.json` 的 `icon` 指定图标名，缺省显示首字母方块。

## 响应式

三档断点：≤640 手机、641–1024 平板、≥1025 桌面。列表行在平板隐藏输出与发布日期列，在手机改为两行；地址行在手机上地址独占一行、按钮换行铺满；网格子项一律 `minmax(0, 1fr)` / `min-width: 0`，防止代码块撑宽页面。

## 动效

- 状态过渡 120ms，面板 200ms，视图切换约 300ms，缓动 `--ease-out`。跨页与主题切换用 View Transitions；筛选只过渡列表区。
- `prefers-reduced-motion` 下保留淡入淡出，去掉位移与缩放；字墙静止。

## 检查

`pnpm check` 运行 `scripts/check-design.mjs`：组件样式出现写死的字号、行高、间距、字面颜色、`transition: all` 或非零圆角即失败。确需例外时在同一行写 `design-ok` 与原因；新数值先加到 `tokens.css`。
